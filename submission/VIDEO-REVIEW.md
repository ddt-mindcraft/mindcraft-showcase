# 영상 사용 검토

코치마크를 더한 50초 제품 소개 영상은 흐름을 빠르게 이해하는 자료로 유지합니다. 이전 개발 버전의 오프라인 녹화에 자막·확대·시간 편집이 있으며 도입·마무리는 생성 캐릭터 연출입니다. 최종 r3 실행 증거는 새 캡처 5장과 capture-report.json입니다. 10초 생성 콘셉트 영상은 접힌 상세 항목에 유지합니다. 어떤 영상도 실제 모델 응답 품질·최종 버전 전체 기능을 증명한다고 표시하지 않습니다.

이번 제출 v10에는 product-demo-v2의 약 49.15초 코치마크 편집본을 보관합니다. 영상 개선 작업에서 추가 생성 중인 장면은 이 스냅샷의 완료 주장에 포함하지 않습니다. 영상 내용·모델 사용은 동봉 video-manifest.json을 기준으로 합니다.
