# 제출 본문 이미지 · 업로드 순서

아래 6장을 번호 순서대로 첨부합니다. 첫 번째 WebP가 썸네일입니다.

1. **01-thumbnail.webp** — AI 딸깍, 야근 싹뚝
   최종 선택본: 딸깍·싹뚝이 주황에서 보라색으로 순서대로 바뀌며 눌림·절단 동작

2. **02-easy-start.png** — AI 용어를 몰라도, 내 일은 아니까.
   단일 실행 파일과 온보딩으로 쉽게 시작

3. **03-workflow.png** — 맡긴 일은, 확인하며 끝까지.
   자료 확인 → 문서 작성 → 저장 승인 → 기록

4. **04-continuity.png** — 어제의 수고를, 오늘의 출발점으로.
   결과 보관 → 사용 선택 → 새 요청에 활용

5. **05-models-pi.png** — 모델은 일에 맞게, 기반은 가볍게.
   Planner·Worker 모델 역할 배정과 Pi 기반

첫 WebP는 문구 색 변화 최종본입니다(640×360, 54프레임, 4.5초, 527,174바이트, 무한 반복). 첫·마지막 프레임 픽셀이 동일합니다. 2–5번 4장은 현재 제품 기능을 설명하는 콘셉트 이미지입니다. 실제 동작 캡처와 데모는 소개 페이지에 있습니다.

이전 정지형 표지는 gallery-fallback/01-cover.png에 별도 보존했습니다. 기본 업로드 6장에는 포함하지 않습니다.

6. **06-animation.webp** — 추가 애니메이션
   사용자 제공 Animation.gif를 무손실 WebP로 변환했습니다. 1725×842, 388프레임, 33.34초이며 프레임별 재생 시간과 반복 설정을 보존했습니다. 마지막에 첨부합니다.
