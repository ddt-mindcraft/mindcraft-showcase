# 60초 데모 진행안

시작 멘트: “AI에게 일을 맡기는 데 필요한 도구를 하나로 묶었습니다. 처음은 쉽게, 결과는 확인하고, 다음 일로 이어갑니다.”

| 시간 | 화면과 행동 | 말할 내용 |
|---|---|---|
| 0–10초 | 첫 화면, 샘플 시작 | “에이전트를 몰라도 작은 일부터 시작합니다.” |
| 10–25초 | 세 자료 확인 후 진행, 결과 열기 | “어떤 자료로 만든 결과인지 함께 확인합니다.” |
| 25–40초 | 파일로 저장, 변경 내용 승인 | “내 파일을 바꾸기 전에는 내가 확인합니다.” |
| 40–50초 | 작업 기록에서 결과 다시 열기 | “지난 결과를 다음 작업의 출발점으로 남깁니다.” |
| 50–60초 | 모델 역할 설정 또는 소개 탭 | “모델은 일에 맞게 나누고, Pi 기반에 작업·지식 하네스를 더합니다.” |

시연 시작 또는 화면 자막에 “오프라인 샘플 · 실제 AI 호출 없음”을 표시합니다. AI가 실시간으로 새 문서를 생성했다고 설명하지 않습니다. 모델 설정 화면은 역할 배정 인터페이스이며 연결 성공 증거가 아닙니다.

설계·리뷰·실행·테스트는 **사용자가 맡긴 작업**에 적용하려는 제품 컨셉입니다. 이 짧은 샘플이 모든 종류의 작업에서 전체 검증을 수행한다는 의미는 아닙니다.
