# 60초 체험 안내

- 0–10초: EXE 실행 → 처음 안내에서 ‘나중에 설정하고 샘플 체험’. 실행 환경과 기록 저장 준비 상태를 확인합니다.
- 10–25초: ‘먼저 작은 프로젝트를 체험해 보세요’ → 온담 북클럽 자료 세 개 → ‘이 자료로 진행’.
- 25–40초: 최신 결과를 열고 준비안과 출처를 함께 읽습니다.
- 40–50초: ‘파일로 저장’ → 경로·변경 내용 확인 → 승인.
- 50–60초: ‘작업 기록’ → 같은 결과 다시 열기.

더 볼 분은 결과의 ‘자료로 보관’으로 후보를 만들고 자료함에서 ‘이 자료 사용하기’를 선택하세요. 오프라인 샘플은 모델을 호출하지 않고 제공 자료를 조합합니다. 실제 모델 연결은 별도 준비가 필요합니다. 60초는 안내 분량이며 실행 속도 보장이 아닙니다.
