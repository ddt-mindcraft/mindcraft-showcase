# 최종 r3 EXE 동작 화면

모두 최종 EXE(build-z9OSa3)를 별도 작업 폴더에서 직접 실행한 1440×1000 원본 캡처입니다. IPC 모킹·AI 화면 편집 없이 오프라인 샘플을 실행했습니다. 소개 페이지는 HTML 제목·핵심 기능 태그로 설명을 더합니다. 공식 갤러리에는 업로드하지 않습니다.

- `01-start.png`: **처음이면, 안내부터** — 작업 폴더와 모델 준비 상태를 확인합니다. 계정 없이 샘플부터 시작할 수 있습니다.
- `02-sources.png`: **AI가 볼 자료, 내가 확인** — 이번 요청에 사용할 세 자료의 내용과 출처를 확인한 뒤 진행합니다.
- `03-result.png`: **내 자료가, 바로 읽는 결과로** — 온담 북클럽 준비안과 참고 자료를 함께 읽고 결과 전체를 복사하거나 저장합니다.
- `04-approval.png`: **저장하기 전, 한 번 더 확인** — 실제 파일 경로와 변경 내용을 읽고 이번 저장을 승인합니다.
- `05-history.png`: **한번 한 일, 다시 이어서** — 작업 기록에서 완료된 요청을 찾고 같은 결과를 다시 엽니다.
