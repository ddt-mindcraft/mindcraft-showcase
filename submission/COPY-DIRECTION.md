# 확정 제목과 표현 원칙

MindCraft | AI 딸깍, 야근 싹뚝

기존 보라색 블록 작업실과 실제 GUI 캡처를 유지합니다. 배너에서는 딸깍/싹뚝의 리듬을 살리고, 본문은 구체적인 기능을 짧게 설명합니다.

핵심 다섯 가지: 단일 EXE와 시작 안내 / 설계·리뷰·실행·테스트 워크플로우 / 이전 작업 지식 재사용 / 고성능·저비용 모델 역할 배정 / Pi 오픈소스 기반.

‘딸깍’은 시작 부담을 줄인다는 표현이며, 실제 모델의 계정·인증 준비가 불필요하다는 뜻으로 쓰지 않습니다. ‘야근 싹뚝’은 준비와 반복에 쓰는 시간을 줄이려는 제품 방향이며 검증된 야근 감소 효과나 수치를 주장하지 않습니다.
