하나의 작업을 끝까지 이어주는 여섯 가지

시작은 쉽게.
과정과 결과는 알 수 있게.

MindCraft가 지향하는 제품 경험입니다. 각 기능의 실제 구현·검증 상태는 실행 자료와 함께 공개합니다.

↗01 / 쉬운 시작

하고 싶은 일부터.

실행 파일을 열고 안내를 따라 준비합니다. 평소 말하듯 문서 정리, 자료 분석을 요청하세요.

✓02 / 작업별 워크플로우

만들고, 확인하고.

자료·출처 확인부터 문서 작성·저장 승인까지 연결합니다. 선택한 자료와 결과를 작업 기록으로 남겨 다시 확인할 수 있습니다.

⇄03 / 내 모델 선택

일에 맞는 모델로.

사용할 모델과 연결 서비스를 직접 지정합니다. 모델 하나를 공용으로 쓰거나 일반 작업과 복잡한 계획에 각각 배정합니다.

◎04 / 이해하고 허용

변경 전에 확인.

사용할 자료와 출처를 확인합니다. 파일 변경은 대상과 내용을 보고 결정하고, 외부 폴더 접근도 확인합니다. 저장은 확인한 내용에 대해 한 번씩 승인합니다.

↺05 / 작업 재개

멈춘 자리에서.

작업과 실행 이력을 남겨 취소·종료 후 상태를 확인하고 이어갑니다. 완료 여부가 불확실한 동작은 무조건 반복하지 않습니다.

＋06 / 자료 재사용

다음 일의 재료로.

결과와 출처를 보고 다시 쓸 자료를 고릅니다. 다음 작업에 가져와 처음부터 설명하는 수고를 줄입니다.

작업 이어가기

진행하던 작업의 상태와 이력을 확인해 계속합니다.

결과 재사용

선택해 남긴 결과를 새로운 요청의 자료로 활용합니다.

시작 전 궁금한 것들

알고 시작하세요.

작업 워크플로우는 무엇을 연결하나요?

이번 요청의 자료·출처 확인, 문서 작성, 저장 승인, 작업 기록을 연결합니다. 위 웹 예시는 설계와 검사가 왜 필요한지 설명하는 원리 체험입니다. 제품의 실제 기능은 실행 화면에서 확인할 수 있습니다.

검증 근거는 어디서 볼 수 있나요?

AI-DLC 요구사항·설계·리뷰·테스트 기록을 소스와 함께 공개합니다. 현재 지원 범위와 검증 기록 보기 ↗

에이전트나 하네스를 알아야 하나요?

처음부터 알 필요는 없습니다. 안내를 따라 준비하고 평소 말하듯 요청하도록 설계합니다. 실제 AI를 쓰려면 모델 연결이 필요하고, 샘플은 연결 없이 체험할 수 있습니다.

모든 결과를 자동으로 기억하고 사용하나요?

아니요. 결과의 내용과 출처를 확인하고 사용 가능으로 선택한 자료를 후속 작업에 활용하는 방식입니다.

내 자료가 컴퓨터 밖으로 전달되나요?

선택한 모델 연결에 따라 요청과 관련 자료가 해당 서비스로 전달될 수 있습니다. 연결 정보와 사용할 자료를 확인하는 흐름을 제공합니다.

게임인가요?

Windows 개인 AI 도구입니다. 블록 일러스트는 첫 작업의 결과가 다음 작업의 재료가 된다는 의미를 표현한 콘셉트 이미지입니다.

지금 바로 사용해볼 수 있나요?

r3 첫 릴리스 EXE를 내려받아 샘플부터 체험할 수 있습니다. 실제 GUI 캡처를 먼저 확인하세요. 이 상세 페이지의 웹 체험은 설명용 예시이고, 실제 모델은 Airouter 두 모델의 연결·마커 응답을 확인했습니다. 실행 환경과 지원 범위는 지원 범위를 확인하세요.
