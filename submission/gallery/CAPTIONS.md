# 갤러리 업로드 순서

실제 GUI 캡처 · 개발 중 · 오프라인 샘플(모델 호출 없음).

1. **자료를 고르면, 결과가 한곳에** — 01-result.png

   선택한 자료와 결과 문서를 함께 확인합니다.

2. **설정이 막막해도, 작은 일부터** — 02-easy-start.png

   한국어 안내와 샘플 체험으로 첫 작업을 시작합니다.

3. **내 파일은, 확인하고 저장** — 03-approval.png

   저장 경로와 변경 내용을 보고 승인합니다.

4. **지난 일을 다시 설명하지 않도록** — 04-history.png

   작업 기록에서 이전 결과를 다시 엽니다.

5. **모델은 일에 맞게** — 05-model-roles.png

   일반 작업과 복잡한 계획에 쓸 모델 역할을 설정합니다.

구현·검증 범위와 버전은 STATUS-AND-EVIDENCE.md에 안내합니다.
