# 갤러리 업로드 순서

실제 Electron 로컬 테스트 캡처 5장입니다. 합성 UI나 생성 이미지가 아닙니다. PNG 원본을 수정하지 않았습니다. 모든 샘플은 모델 호출이 없는 오프라인 체험입니다.

1. **자료에서 결과까지, 한 화면에서** — 01-result.png

   선택한 세 가지 자료의 출처와 완성된 문서를 함께 확인합니다. 오프라인 샘플 결과이며 실제 모델이 생성한 문서는 아닙니다.

2. **전문 용어 대신, 하고 싶은 일부터** — 02-easy-start.png

   한국어 작업실에서 요청을 입력하거나 작은 프로젝트 체험으로 시작합니다.

3. **내 파일을 바꾸기 전에, 내가 확인** — 03-approval.png

   저장할 경로와 변경 내용을 확인하고 이번 작업의 저장을 승인하거나 거부합니다.

4. **지난 작업을, 다음 시작점으로** — 04-history.png

   작업 이력을 검색하고 저장된 실행 결과를 다시 엽니다. 이 화면만으로 지식 재사용의 전체 검증을 주장하지 않습니다.

5. **모델은 필요한 역할에 맞게** — 05-model-roles.png

   일반 작업·저비용 역할과 계획·복잡한 분석·고성능 역할의 설정 화면입니다. 실제 제공자 연결 성공이나 비용 절감 실측 화면은 아닙니다.
