# 60초 소개·데모

“회사에서 AI 에이전트를 쓰고 싶은데 설치부터 막막했던 적 있나요? MindCraft는 비개발자도 자기 업무부터 시작하도록 만듭니다.”

| 시간 | 보여줄 것 | 한 문장 설명 |
|---|---|---|
| 0–10초 | 첫 화면 | “실행 파일 하나, 친절한 한국어 안내로 시작합니다.” |
| 10–25초 | 샘플 자료 선택 → 결과 | “도구를 조립하는 대신, 쓸 자료와 원하는 일을 고릅니다.” |
| 25–40초 | 저장 승인 | “결과를 읽고, 내 파일에 반영할 내용을 확인합니다.” |
| 40–50초 | 작업 기록 | “지난 일을 다음 시작점으로 남깁니다.” |
| 50–60초 | 모델 역할 설정 | “Pi 기반에 작업·지식 하네스를 더하고, 모델은 역할에 맞게 배정합니다.” |
