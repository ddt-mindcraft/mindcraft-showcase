# 제출 입력용 최종 원고

## 프로젝트 제목

MindCraft | 비개발자도 시작하는 개인 AI

## 프로젝트 설명

“회사 일에 AI 에이전트를 써보고 싶은데, 설치부터 막막해요.”
“업무 절차와 자료까지 연결하는 하네스는 어떻게 설정하죠?”

MindCraft는 이런 시작의 장벽을 낮추는 Windows 개인 AI입니다. 비개발자도 실행 파일 하나와 친절한 한국어 안내로, 하고 싶은 일부터 시작하도록 만듭니다.

• 쉽게 시작: 필수 하네스를 한 프로그램에 담아, 도구를 따로 조립하는 부담을 줄입니다.
• 맡긴 일 확인: 설계→리뷰→실행→테스트의 작업 절차로 요청과 결과를 확인하도록 설계합니다.
• 다음 일로 연결: 지난 작업과 자료를 지식으로 남겨 새 업무에 활용합니다.
• 모델은 적재적소에: 고성능·저비용 모델을 역할별로 배정해 비용과 성능의 균형을 추구합니다.
• Pi 기반: 가벼운 오픈소스 기반에 업무용 하네스를 더합니다.

Claude Code가 소프트웨어 개발을 중심에 둔다면, MindCraft는 비개발자가 자기 업무를 맡기기 쉬운 시작과 작업 흐름에 초점을 둡니다.

처음은 쉽게, 맡긴 일은 확인하고, 다음 일로 이어서.
개발 중 · 실제 GUI의 오프라인 샘플 공개(모델 호출 없음).

## 실행 안내

Windows x64에서 동봉 EXE를 쓰기 가능한 별도 폴더에 놓고 실행하세요. 첫 화면의 ‘먼저 작은 프로젝트를 체험해 보세요’ → 자료 확인 → ‘이 자료로 진행’ → 결과 열기 순서로 시작합니다. ‘파일로 저장’에서 변경을 승인하고 ‘작업 기록’에서 다시 열어보세요. 샘플은 모델 계정·호출 비용 없이 체험합니다. 개발 중이며 최신 화면과 동봉 EXE에는 UI 차이가 있습니다. 실제 모델 연결 등 검증 범위는 STATUS-AND-EVIDENCE.md를 참고하세요.

## 실행 링크

선택 필드는 비워 둡니다. 소개 링크는 설명에 포함했습니다. EXE는 별도 전달용이며 공개 다운로드 링크는 없습니다.
