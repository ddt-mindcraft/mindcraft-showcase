## 프로젝트 설명

설정하느라 한참, 같은 설명을 또 한 번.
정작 내 일은 언제 하죠?

MindCraft는 준비와 반복에 쓰는 시간을 줄이려는 Windows 개인 AI입니다. 처음 쓰는 사람도 실행 파일 하나와 시작 안내로, 자기 업무부터 맡길 수 있도록 만듭니다.

① 시작은 딸깍
필수 하네스와 시작 안내를 한 프로그램에. 에이전트와 도구를 따로 구성하는 부담을 줄입니다.

② 맡긴 일은 확인
설계→리뷰→실행→테스트의 작업 워크플로우로 요청과 결과를 확인하도록 설계합니다.

③ 지난 일은 다음 일로
작업 이력과 결과를 지식으로 남기고, 다시 쓸 자료를 골라 새 업무에 활용합니다.

④ 모델은 일에 맞게
고성능·저비용 모델을 단계별 역할에 배정해 비용과 성능의 균형을 추구합니다.

⑤ 기반은 가볍게
Pi 오픈소스 기반에 작업·지식 하네스를 더해 빠르고 안정적인 동작을 지향합니다.

AI 딸깍, 야근 싹뚝.
준비는 줄이고, 맡긴 일은 확인하고, 다음 일은 더 수월하게.

개발 중 · 실제 앱의 오프라인 샘플 공개(모델 호출 없음).

## 실행 안내

Windows x64에서 동봉 EXE를 쓰기 가능한 별도 폴더에 놓고 실행하세요. 첫 화면의 ‘먼저 작은 프로젝트를 체험해 보세요’ → 자료 확인 → ‘이 자료로 진행’ → 결과 열기 순서로 시작합니다. ‘파일로 저장’에서 변경을 승인하고 ‘작업 기록’에서 다시 열어보세요. 샘플은 모델 계정·호출 비용 없이 체험합니다. 개발 중이며 최신 화면과 동봉 EXE에는 UI 차이가 있습니다. 실제 모델 연결 등 검증 범위는 STATUS-AND-EVIDENCE.md를 참고하세요.

## 실행 링크

선택 필드는 비워 둡니다. 소개 링크는 설명에 포함했습니다. EXE는 별도 전달용이며 공개 다운로드 링크는 없습니다.
