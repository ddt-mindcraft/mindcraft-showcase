MindCraft는 준비와 반복을 줄이는 Windows 개인 AI입니다. 에이전트와 하네스를 따로 꾸릴 필요 없이, 실행 파일 하나와 시작 안내로 내 업무부터 시작합니다.

① 시작은 딸깍 — 필요한 도구와 안내를 한 프로그램에. 모델 없이 샘플부터 체험하세요.
② 맡긴 일은 확인 — 자료·출처 확인부터 문서 작성, 저장 승인까지 작업 흐름으로 연결합니다.
③ 지난 일은 다음 일로 — 이력과 결과를 보관하고, 골라 둔 지식을 새 작업에 활용합니다.
④ 모델은 일에 맞게 — 일반 작업과 복잡한 계획에 모델을 나눠 배정합니다. 비용·성능의 균형을 위한 선택입니다.
⑤ 기반은 가볍게 — Pi 에이전트 기반에 작업·지식 하네스를 더했습니다.

9/9 r3 첫 릴리스 완료. 문서 분석·작성, 승인 후 저장, 기록·지식 재사용을 제공합니다. 샘플은 모델 호출·비용 없이 체험할 수 있습니다.
설계→리뷰→실행→테스트의 자동 검증 확대는 다음 단계입니다.

AI 딸깍, 야근 싹뚝. 준비는 줄이고, 다음 일은 더 수월하게.

### 실행 방법

Windows x64에서 EXE를 쓰기 가능한 별도 폴더에 놓고 실행하세요. 첫 안내의 ‘나중에 설정하고 샘플 체험’ → ‘먼저 작은 프로젝트를 체험해 보세요’ → 자료 3개 확인 → ‘이 자료로 진행’ → 결과 열기 순서입니다. ‘파일로 저장’에서 경로·내용을 승인하고 ‘작업 기록’에서 다시 여세요. 샘플은 모델 호출·비용이 없습니다. 실제 AI는 모델·인증 정보를 직접 연결합니다. r3는 문서 분석·작성용이며 명령 실행은 지원하지 않습니다. 새 Windows 환경 전면 검증은 후속입니다. EXE는 코드 서명되지 않아 Windows 경고가 나타날 수 있습니다.
