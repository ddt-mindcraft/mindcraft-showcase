Windows x64에서 동봉 MindCraft-0.1.0-windows-x64.exe를 쓰기 가능한 별도 폴더에 놓고 실행하세요. ‘먼저 작은 프로젝트를 체험해 보세요’ → 자료 3개 확인 → ‘이 자료로 진행’ → 결과 열기 → ‘파일로 저장’ → 경로·변경 확인 후 승인 → ‘작업 기록’에서 다시 열기 순서입니다. 샘플은 인터넷·모델 계정 없이 동작하며 AI 호출 비용이 없습니다. 실제 모델 연결은 별도 검증 중입니다. EXE는 검증된 이전 빌드이며 9/9 최신 캡처와 UI 차이가 있습니다. 안내 페이지는 소개·화면 열람용이고 실행 파일 다운로드 페이지는 아닙니다.
