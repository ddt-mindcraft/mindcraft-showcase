# 데모 v5 제작 및 검증 기록

실제 GUI 녹화를 바탕으로 만든 50.1초, 30fps 안내 영상입니다. 6단계 흐름을 12개 안내 장면으로 나누었습니다. 가로형은 1920×1080, 모바일형은 1080×1440입니다.

## 발견한 문제와 수정

이전 v4는 WebM의 불안정한 프레임 속도 상태에서 tpad를 적용해 앞부분 정지가 누락되었고, 반복 이미지 입력 때문에 마지막 강조 화면이 연장되었습니다. 스크롤 후 참고 자료의 좌표도 116px 어긋났습니다. 기존 재생·메타데이터 검사는 이 결함을 잡지 못했습니다. 상세 원인과 이전 화면은 demo-alignment-review/REVIEW.md에 기록했습니다.

v5는 원본을 30fps로 정규화하고, 안내할 실제 프레임을 직접 반복한 뒤 강조 없는 동작 프레임을 기록합니다. tpad·반복 오버레이·장면 겹침 전환을 사용하지 않습니다. 강조는 동작 4프레임 전에 제거합니다. 장면별 실제 원본 좌표를 측정하고 영상 확대와 강조에 같은 좌표 변환을 사용합니다. 저장 버튼·파일 이름·승인 버튼을 각각 설명하고, 화면에 이미 끝난 동작을 요구하는 문구를 제거했습니다.

모바일은 같은 시간표의 확대된 세로형 영상과 큰 설명 글씨를 제공합니다. 화면 폭이 바뀌어도 재생 위치와 상태를 유지하며, JavaScript가 없어도 직접 열기 링크를 제공합니다.

## 검증 범위

- 가로·세로 각 1,503프레임, 총 3,006프레임을 디코딩하여 안내 존재/제거 시점과 안내 중 앱 영역 정지를 검사: PASS.
- 12개 안내 장면의 대상 버튼·자료·입력란과 설명을 원본 정지 화면으로 확인.
- 데스크톱·모바일 재생, 탐색, 화면 폭 전환 시 위치·재생 상태 유지, 페이지 오류, 가로 넘침, JavaScript 없는 대체 링크: PASS.
- 원본 영상 SHA-256와 장면별 프레임 범위·좌표는 video/product-demo-v5/manifest.json, 출력 해시와 수치는 verification.json에 수록.

검증은 이 녹화와 정의된 장면에 대한 검사이며 모든 앱 상태를 자동 검증한 것은 아닙니다.

## 영상과 실행 증거 구분

앱 데모 원본은 이전 개발 GUI의 오프라인 샘플 녹화이며 최종 r3 EXE 녹화나 실제 모델 응답 증거가 아닙니다. 최종 실행 근거는 demo-images의 최종 EXE 캡처와 기존 r3 검증 기록입니다. 상단 소개 영상은 사용자 제공 최종본-중간화질.mp4 원본(38.56초)을 유지합니다.

## 재현

Windows의 맑은 고딕 글꼴, Python Pillow·imageio-ffmpeg·numpy가 필요합니다. evidence/video/product-demo-v5/render.py를 실행하면 옆 product-demo-v1/raw-session.webm에서 두 영상을 만듭니다. 이어 verify-video.py로 전체 프레임을 검사합니다. verify-site.mjs는 작업 루트의 site 디렉터리와 로컬 Playwright/Chrome 경로를 사용하는 제작 환경 검증 스크립트입니다.
