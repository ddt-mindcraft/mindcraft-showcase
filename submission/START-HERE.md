# 최종 제출 자료 1.0.3

## 제출 순서

1. 제목·설명·실행 안내는 SUBMISSION.md에서 복사합니다. 항목별 텍스트는 fields/에 있습니다.
2. 소스 업로드에는 artifacts/MindCraft-submission-v1.0.1-source.zip 한 개를 사용합니다.
3. 본문 이미지에는 gallery/의 01-thumbnail.webp → 02-easy-start.png → 03-workflow.png → 04-continuity.png → 05-models-pi.png 순서로 총 5장을 첨부합니다. 첫 이미지가 썸네일입니다. gallery-set-v3.zip은 이 이미지들을 편하게 받는 압축 파일이며, 풀어서 개별 이미지를 첨부합니다.
4. 실행·소개 URL은 fields/submission-fields.json 또는 SUBMISSION.md의 값을 사용합니다.

최종 썸네일은 딸깍·싹뚝 글자가 보라색으로 순서대로 바뀌는 선택본입니다. 640×360, 4.5초, 약 527KB이며 첫·마지막 프레임이 같습니다.

## 자료 위치

| 위치 | 용도 |
|---|---|
| gallery/ | 실제로 첨부할 최종 이미지 5장과 설명 |
| artifacts/ | 평가용 소스 ZIP, 검증된 EXE, 원본 소스 |
| SUBMISSION.md · fields/ | 제출 원고와 입력값 |
| website/ | 소개 페이지와 제품 데모 사본 |
| demo-images/ | 최종 EXE 실제 동작 캡처 |
| evidence/ | AI-DLC·데모·썸네일 검증 근거 |
| archive/ · original-gallery/ · gallery-fallback/ | 이전 자료·원본·대안 보관 |

전체 자료 ZIP은 보관용이며 소스 항목이나 이미지 항목에 그대로 첨부하지 않습니다. 전체 자료 버전은 1.0.3, 평가용 소스 패키지는 1.0.1, 앱은 검증된 0.1.0/r3입니다.
